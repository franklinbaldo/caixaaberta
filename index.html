Método

Uma observação do Brasil, todos os dias.

1. Observar

Um GitHub Action baixa diariamente as listas publicadas pela Caixa para as 27 UFs.

2. Organizar

Os CSVs são normalizados, enriquecidos e publicados como um único retrato nacional com scrape_date.

3. Preservar

Cada dia fica no Internet Archive. A busca usa o retrato corrente sem transformar o site na fonte canônica.

Caixa Aberta é um projeto independente. Os dados de oferta vêm da Caixa Econômica Federal e cada observação diária é preservada no Internet Archive.
